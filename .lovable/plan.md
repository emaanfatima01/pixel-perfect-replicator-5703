# FYPMS visual polish

## Goal
Give the existing FYPMS a more polished, consistent university-product feel while preserving its content, colors, functionality, and stored data.

## Work
- Refine shared layout elements: public navigation/footer, authenticated sidebar/header, panels, badges, and statistic cards.
- Improve the homepage hierarchy and consistency of its sections and cards; apply the same restrained card and focus treatment to related public pages and project views.
- Keep the established Fraunces/Manrope typography and semantic color tokens; avoid changing behavior or adding features.
- Check the homepage and authenticated-style layouts at desktop and mobile widths, and confirm the preview builds cleanly.

## Technical details
- Make focused changes to the existing Tailwind v4 theme and shared React components/pages.
- Reuse existing shadcn controls, semantic tokens, and reduced-motion/accessibility patterns.
